# Автокөлікті жалға беру ақпараттық жүйесі

## Жоба туралы

Бұл жоба автокөліктерді жалға беру, брондау және әртүрлі қаладағы филиалдар арасында қайтару процесін автоматтандыруға арналған.

Жүйенің негізгі ерекшелігі — клиент автокөлікті бір қаладан алып, басқа қаладағы филиалға қайтара алады.

Мысалы: клиент Toyota Camry автокөлігін Алматы филиалынан алып, Семей филиалына қайтарады. Жүйе автокөліктің орналасқан жерін автоматты түрде Семей деп жаңартады және күйін «Бос» деп өзгертеді.

## Жүйенің мүмкіндіктері

- Автокөліктерді қарау
- Автокөлікті брондау
- Автокөлікті жалға алу
- Автокөлікті басқа қаладағы филиалға қайтару
- Автокөліктің күйін жаңарту
- Автокөліктің орналасқан филиалын жаңарту
- Клиенттер туралы мәліметтерді сақтау
- Филиалдар туралы мәліметтерді сақтау

## Деректер базасы

Жоба Microsoft SQL Server көмегімен жасалды.

Негізгі кестелер:

- Filialdar
- Avtokolikter
- Klientter
- ZhalgaAlu
- Brondau

SQL коды `docs/database` бөлімінде сақталған.
