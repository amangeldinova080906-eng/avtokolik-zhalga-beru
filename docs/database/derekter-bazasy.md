# Деректер базасының құрылымы

Автокөлікті жалға беру жүйесінде клиенттер, автокөліктер, филиалдар және жалға алу туралы ақпарат сақталады.

## Клиенттер
- Клиент ID
- Аты-жөні
- Телефон нөмірі

## Автокөліктер
- Автокөлік ID
- Маркасы
- Моделі
- Мемлекеттік нөмірі
- Күйі: Бос немесе Жалға берілді
- Қазіргі орналасқан филиалы

## Филиалдар
- Филиал ID
- Қала
- Мекенжай

## Жалға алу
- Жалға алу ID
- Клиент ID
- Автокөлік ID
- Алу филиалы
- Қайтару филиалы
- Алу күні
- Қайтару күні
- Жалға алу күйі

## Жүйенің ерекшелігі
Клиент автокөлікті бір филиалдан алып, басқа қаладағы филиалға қайтара алады. Автокөлік қайтарылған кезде оның күйі «Бос» болып, қазіргі орналасқан филиалы автоматты түрде жаңартылады.
